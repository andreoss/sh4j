= sh4j

A POSIX `sh` command-language interpreter in pure Java 21, buildable as a
GraalVM native image.

== Install

link:https://central.sonatype.com/artifact/io.github.andreoss/sh4j[io.github.andreoss:sh4j] is on Maven Central.

[source,xml]
----
<dependency>
  <groupId>io.github.andreoss</groupId>
  <artifactId>sh4j</artifactId>
  <version>1.0.7</version>
</dependency>
----

== Build

[source,sh]
----
mvn compile
----

== Test

[source,sh]
----
mvn test
mvn jacoco:report
----

The coverage report is written to `target/site/jacoco/index.html`.

== Run

[source,sh]
----
java -cp target/classes io.github.andreoss.sh4j.Main -c 'echo hello'
java -cp target/classes io.github.andreoss.sh4j.Main script.sh arg1 arg2
java -cp target/classes io.github.andreoss.sh4j.Main -i
----

Native image, with a GraalVM JDK:

[source,sh]
----
mvn package -Pnative-image
./target/sh4j -c 'echo hello'
----
